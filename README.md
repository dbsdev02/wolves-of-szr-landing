# Wolves of SZR

Create a premium, high-converting real estate landing page for Wolves International promoting a luxury residential project called “Wolves of SZR” in Dubai.

The website should feel like a high-end Dubai real estate campaign, combining cinematic visuals, premium typography, strong conversion-focused UX, subtle animations, and a sophisticated luxury aesthetic.

CORE OBJECTIVE

The primary goal is lead generation.

The landing page should persuade potential buyers and investors to:

Explore the Wolves of SZR project

Understand the location and investment opportunity

View key property details

Request project information

Book a private consultation / viewing

Submit their contact details

The page should feel exclusive and premium without becoming overly flashy.

BRAND

Brand: Wolves International

Project: Wolves of SZR

Location: Sheikh Zayed Road, Dubai, UAE

Positioning:
A premium Dubai residential opportunity located around Sheikh Zayed Road, targeting international investors and high-net-worth buyers.

Tone:

Luxury

Modern

Confident

Architectural

Exclusive

Investment-focused

Minimal

Premium Dubai aesthetic

Avoid generic real-estate-template styling.

Do NOT make it look like a normal property listing website.

DESIGN DIRECTION

Use a dark luxury visual system.

Primary background:

Deep black

Charcoal

Very dark graphite

Accent:

Warm champagne gold / muted metallic gold

Typography:

Large editorial-style headlines

Clean modern sans-serif for body copy

Strong contrast between large headlines and minimal supporting text

Use generous whitespace.

Use subtle glassmorphism only where appropriate.

Use thin borders, subtle gradients and soft shadows.

Do NOT overuse gold.

The overall feeling should be:
Luxury Dubai + Architectural Magazine + Private Investment Opportunity
